# Demo Asset Provenance (DFS-002)

DeepListener ships one bundled demo so a new user can experience the
sentence-level learning loop without an API key or media import.

## Audio

| Asset | Path | Source | License |
|---|---|---|---|
| `demo-listening.mp3` | `public/demo/demo-listening.mp3` | Generated by `ffmpeg -f lavfi -i sine=frequency=523:duration=5` | None — fully synthetic, no copyright |

The audio is a 5-second 523 Hz sine wave generated by FFmpeg's lavfi source.
It contains no speech, no music, and no third-party content. Attribution: none
required. Redistribution: unrestricted.

## Timeline

The bundled sentence timeline is hand-authored in `src/lib/demo-seed.ts`
(`DEMO_SENTENCES`). It is two short textual cues mapped to time offsets within
the 5-second clip. No provider transcription call is made for the demo
(DFS-002: the demo path never contacts an external provider).

## Ownership / isolation

Demo records use `Track.trackType = "DEMO"` so they are distinguishable from
personal library data and removable without affecting personal tracks, notes,
or review history (DFS-004). See `src/lib/demo-seed.ts`.
