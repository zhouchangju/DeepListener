# 普通英语学习者首次成功体验 PRD

**版本：** 1.0
**状态：** Target state；部分功能已实施，正式验收仍按 [implementation-status.md](./implementation-status.md) 执行
**日期：** 2026-08-04
**OpenSpec：** `ordinary-learner-first-success`
**产品边界：** Local-first、单用户、自带媒体；外部转写仍为可选 BYOK

## 1. Answer Firs

DeepListener 的首要产品目标不是让用户“完成配置”，而是让普通英语学习者在首次打开后的 5 分钟内，无需终端、无需 API 密钥、无需自备素材，完成一次真实英语句子的盲听、揭示、收藏和后续复习发现。

正式推广前必须同时满足：

- 支持平台存在可验证的安装包；
- 首次启动自动完成本地数据初始化；
- Demo 是真实英语语音且具有清晰再分发权；
- 所有首次会话错误都提供有效恢复动作；
- 5 名目标用户可以不依赖开发者完成核心旅程；
- 安装、升级、失败恢复均不损失数据库、媒体和学习历史。

## 2. 用户与被雇佣任务

### 2.1 主用户：非技术型独立学习者

- 会安装常见桌面应用，但不会使用终端、npm、Prisma 或环境变量。
- 使用播客、课程、访谈、视频或考试材料练习英语。
- 可以在明确指导下申请服务商密钥，但不理解 Provider、模型和代理配置。
- 关心隐私、费用和自己的学习记录是否会丢失。

### 2.2 次用户：高级自托管用户

- 继续使用 Server edition；可以接受命令行和 `.env`。
- 需要准确的技术诊断，不应被面向普通用户的抽象阻断。

### 2.3 Jobs to Be Done

| ID | 用户任务 |
| --- | --- |
| JTBD-01 | 当我第一次打开应用时，我想先知道它是否真的能帮助我听懂英语，而不是先注册和配置。 |
| JTBD-02 | 当我导入自己的材料时，我想知道是否需要付费转写，以及有没有字幕免密钥路径。 |
| JTBD-03 | 当处理需要几分钟时，我想知道进展到哪里、能否关闭应用、失败后是否能继续。 |
| JTBD-04 | 当发生错误时，我想知道我能做什么，而不是看到开发者错误或无效重试。 |
| JTBD-05 | 当我保存一个困难句时，我想知道下一步何时、在哪里复习。 |
| JTBD-06 | 当我更新或换机器时，我想保留媒体、笔记、收藏和复习历史。 |

## 3. 当前体验问题

| 问题 | 用户后果 | 优先级 |
| --- | --- | --- |
| Desktop 平台覆盖和签名不足 | 大量普通用户无法安装或不敢绕过系统警告 | P0，依赖上游发行变更 |
| Demo 是正弦波而非英语语音 | 能验证播放器，不能证明学习价值 | P0 |
| 引导只介绍页面，完成按钮不执行学习动作 | 用户看完仍不知道下一步 | P0 |
| 数据库未就绪仍可进入资料库 | 落入“出了点问题/重试”死循环 | P0 |
| 转写失败删除已上传媒体 | 重传、重等、可能重复产生费用 | P0 |
| Provider 选择缺少决策信息 | 用户不知道选谁、花多少钱、是否安全 | P1 |
| FSRS、Vault、Provider、内部阶段过早出现 | 增加认知负担，像专业工具而非学习产品 | P1 |
| 无明确 SRT/VTT 个人字幕导入路径 | 用户被迫配置外部转写 | P1 |
| 自定义引导存在焦点与遮罩风险 | 键盘和辅助技术用户无法可靠完成 | P1 |

## 4. 产品原则

1. **先体验，后配置。** 默认主路径是 Demo；个人媒体配置是第二路径。
2. **一个页面只要求一个关键决定。** 不同时要求选择 Provider、理解费用、安装 FFmpeg 和导入文件。
3. **按钮必须兑现承诺。** “开始学习”必须进入学习；“修复”必须执行或精确引导修复；不能成功的“重试”不出现。
4. **使用学习者语言。** 默认说“收藏句子”“今天要复习”“转成带时间的字幕”，高级层再显示 Vault、FSRS、Provider。
5. **不可恢复损失为零。** 用户媒体和学习数据优先于界面便利。
6. **外部费用必须由用户发起。** 任何可能联系 Provider 或产生费用的动作必须明确说明并由用户确认。

## 5. 目标首次会话

```tex
安装并启动
  -> 自动准备本地数据
  -> 欢迎页：先体验 Demo / 使用我的素材
  -> 真实英语 Demo（默认盲听）
  -> 揭示文本并重听
  -> 收藏一条困难句
  -> 显示“今天稍后复习”与收藏入口
  -> 选择：继续 Demo / 导入自己的素材
```

### 5.1 Demo 路径

- 不要求 Provider、网络、麦克风或个人文件。
- 使用 20–45 秒、2–4 句真实英语语音，难度和口音在素材说明中标明。
- 引导只覆盖当前需要的控件；每一步必须完成真实动作后才能自动前进。
- 引导可以跳过、重播和退出；退出不删除 Demo 或个人数据。
- 完成标准：至少播放/暂停、揭示文本、定位一句、收藏一句，并看到后续复习位置。

### 5.2 个人素材路径

用户先选择素材条件，而不是先选 Provider：

1. 视频含字幕：直接导入并尝试读取内嵌字幕；
2. 媒体旁有 SRT/VTT：同时选择并本地解析；
3. 没有字幕：再进入转写服务商配置；
4. 仅想体验：随时返回 Demo。

### 5.3 Provider 配置路径

- 默认显示一个“推荐给大多数用户”的选择，同时允许展开比较全部服务商。
- 对每个服务商说明：适用场景、是否由第三方接收音频、费用由谁收取、密钥去哪里申请、应用是否会显示或上传密钥。
- 不在页面打开时探测服务商；测试连接是显式动作，并说明可能产生外部请求。
- 申请帮助使用稳定步骤和官方链接，不硬编码容易过时的具体价格承诺。

## 7. 状态与错误文案契约

每个错误必须包含四部分：

1. **发生了什么：** 使用用户能理解的描述；
2. **影响范围：** 是否影响媒体、字幕、密钥、数据库或仅当前操作；
3. **已保留内容：** 明确告诉用户哪些工作没有丢失；
4. **有效动作：** 重试、换 Provider、打开设置、选择字幕或导出诊断。

错误分类至少包括：

| 类别 | 示例动作 |
| --- | --- |
| 数据库未准备好 | Desktop 自动恢复或进入恢复页；Server 显示精确维护命令与文档链接 |
| FFmpeg 缺失 | 允许纯音频；视频/导出入口说明受限功能 |
| 密钥缺失/无效 | 打开对应服务商配置，不要求重传媒体 |
| 网络/代理不可达 | 保留导入任务；提供网络说明和稍后重试 |
| 配额/限流 | 保留任务；显示稍后重试或切换服务商 |
| 字幕不可解析 | 说明字幕问题；允许换字幕或转写，不删除媒体 |
| 转写结果不可用 | 保留媒体；允许换 Provider 或重新处理 |
| 磁盘不足 | 在写入前阻断并说明预计需要空间；不留下伪成功记录 |

## 9. 成功指标与护栏

### 9.1 核心指标

| KPI | 目标 |
| --- | --- |
| KPI-01 安装到 Demo 开始时间 | 中位数 ≤ 3 分钟，P90 ≤ 5 分钟 |
| KPI-02 安装到首次有意义练习 | 中位数 ≤ 5 分钟，P90 ≤ 10 分钟 |
| KPI-03 首次会话终端/开发者代操作 | 0 次 |
| KPI-04 Demo 核心闭环完成率 | ≥ 80%（5 人门槛至少 4 人） |
| KPI-05 个人媒体路径发现率 | ≥ 80% |
| KPI-06 可恢复错误自行恢复率 | ≥ 80% |
| KPI-07 重复上传率 | 可恢复转写失败场景为 0 |

### 9.2 数据安全护栏

- 迁移、升级、重试和回滚后的数据库、媒体、收藏、复习与学习时间不变量全部通过。
- 无密钥 Demo/字幕路径的外部 Provider 请求为 0。
- 诊断与日志中密钥值、转写全文、用户笔记、媒体内容和绝对私人路径泄漏为 0。
- 未经确认删除个人正式媒体为 0。

### 9.3 测量边界

- 默认不增加远程产品遥测。
- 指标通过受控可用性观察、可选的本地事件导出和自动化 E2E 采集。
- 任何未来远程遥测需要独立隐私决策和显式同意。

## 10. 无障碍目标

- 首次会话、设置、恢复和导入路径以 WCAG 2.2 AA 为设计目标。
- 所有关键动作可通过键盘完成；焦点顺序、焦点可见性和 Escape 行为明确。
- 对话框必须有焦点管理和可访问名称；背景不可被屏幕阅读器误操作。
- 状态不能仅依赖颜色；进度变化通过可控的 live region 传达，不重复打扰。
- 200% 缩放与窄屏下主动作、错误恢复和对话框不被裁切。
- 中英文的可访问名称、错误文案和帮助内容一致，不出现无意义的混合语言。

## 11. 发布里程碑

### M0：合同与现状对账

- OpenSpec 任务状态与当前代码一致。
- 首次会话状态机、错误分类、数据不变量和文案词汇表冻结。

### M1：无需密钥的首次成功

- 启动门控、可执行引导、真实英语 Demo 和后续复习发现完成。
- 通过干净配置 E2E 和 3 名内部目标用户会话。

### M2：个人媒体低摩擦路径

- Provider 决策向导、SRT/VTT 配对导入、可恢复导入和更换 Provider 重试完成。
- 故障注入证明不会重复上传或产生重复 Track。

### M3：发行与外部验证

- 上游签名 macOS/Windows 安装包满足平台门槛。
- 完成至少 5 名目标用户会话和全套数据保留验证。
- 所有重复干预点已修复或明确阻断推广。

## 12. 非目标

- 不改变 FSRS 计算、Practice 播放语义、Shadowing 评分逻辑或 Dashboard 指标。
- 不实现云账号、跨设备自动同步、移动端或托管转写订阅。
- 不用营销文案掩盖尚未完成的平台、签名或版权状态。
